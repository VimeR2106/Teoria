# Лабораторная работа №1 — Теория информации

Тема: энтропия объединения двух источников, количество информации.

Откройте `Lab1.sln` в Visual Studio 2022 → **F5**.

## Как пользоваться (как в методичке)

1. Выберите случай:
   - A + p(bj/ai)
   - B + p(ai/bj)
   - матрица p(ai bj)
2. Задайте размеры (максимум **4×4**) → «Задать размеры матрицы».
3. Введите числа (можно с запятой: `0,1`) → «Рассчитать».
4. Смотрите окно «Результаты».

## Пример из тетради (случай 3)

Матрица P(AB) 2×4:

```
0,10  0,06  0,02  0,02
0,16  0,08  0,4   0,16
```

Должно получиться примерно:
- A: 0,2 ; 0,8
- B: 0,26 ; 0,14 ; 0,42 ; 0,18
- H(A) ≈ 0,7219
- H(B) ≈ 1,8733
- H(AB) ≈ 2,4678
- H(B|A) ≈ 1,7459
- H(A|B) ≈ 0,5944
- I(A;B) ≈ 0,1275

## Как считается (как в тетради)

| Шаг | Формула |
|-----|---------|
| Ансамбль A | сумма по строкам P(AB) |
| Ансамбль B | сумма по столбцам P(AB) |
| H(A), H(B), H(AB) | −Σ p log₂ p |
| P(B\|A) | P(AB) / P(A) |
| P(A\|B) | P(AB) / P(B) |
| H(B\|A) | −Σ p(ai)·Σ p(bj\|ai) log₂ p(bj\|ai) |
| H(A\|B) | −Σ p(bj)·Σ p(ai\|bj) log₂ p(ai\|bj) |
| I(A;B) | H(A) − H(A\|B) |
